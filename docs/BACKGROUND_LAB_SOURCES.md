# Background Lab sources

This experimental area intentionally evaluates third-party open-code background components in isolation before any one of them is adopted into the EMPV homepage.

## Imported test components

### Magic UI
- Floating 3D Particles
- Source repository: `magicuidesign/magicui`
- Upstream license: MIT

- Source repository: `DavidHDev/react-bits`
- Upstream license: MIT + Commons Clause as published by the upstream project

## EMPV adaptation rules

- Test palette is kept monochrome.
- Effects are dynamically loaded only when selected.
- The normal homepage has no experimental background unless a `?bg=` query is present.
- Reduced-motion and mobile behavior from upstream components is retained where available.
- The lab exists to compare visual language, not to imply final selection.
